# zwz-blog 视觉与代码规范

> 版本：v1.0 | 更新时间：2026-09-16

## 一、视觉命题

“工程笔记，而不是简历模板”：使用冷白纸面、深墨蓝文字、亮青绿色小面积强调，以及精确的网格和编号，营造克制、可信、可验证的工程气质。

## 二、目录规范

```text
dist/
├── index.html
├── articles/
│   └── evidence-driven-ai-infra.html
└── assets/
    └── styles.css
```

URL 和文件名使用小写 kebab-case。公共样式集中在 `styles.css`；页面不得内联大段样式或引入外部 CDN。

## 三、设计令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--ink` | `#102033` | 主文字与标题 |
| `--muted` | `#5d6b7a` | 次级文字 |
| `--paper` | `#f7f9fb` | 页面背景 |
| `--surface` | `#ffffff` | 卡片与正文 |
| `--line` | `#d9e1e8` | 边框与分隔 |
| `--accent` | `#08a88a` | 链接与重点 |
| `--navy` | `#0d2b45` | 深色区域 |

主色面积保持克制；强调色只标记可交互内容和少量关键词。

## 四、排版

- 字体：系统无衬线字体栈，中文优先 PingFang SC。
- 正文：`1rem` 起，文章正文桌面端约 `1.0625rem`，行高 1.8。
- 标题使用紧凑字距但不得重叠；正文行宽控制在 68 个英文字符附近。
- 元数据最小 0.8125rem，仅用于发布日期、阅读时长等非关键内容。

## 五、布局与响应式

- 最大页面宽度 1180px，左右留白使用 `clamp()`。
- 桌面首页采用信息列 + 主内容列；小于 820px 变为单列。
- 小于 560px 时导航允许换行，卡片内边距收紧。
- 所有页面在 200% 文本缩放下仍可阅读，不依赖固定高度。

## 六、交互与可访问性

- 链接和按钮必须有 44px 左右的可点击高度或足够内边距。
- `:focus-visible` 使用 3px 高对比描边。
- 支持 `prefers-reduced-motion`，减少动效时关闭位移过渡。
- 装饰性网格不得影响内容对比度或被辅助技术朗读。

## 七、内容规范

- 不使用“精通”“大幅提升”等无证据结论。
- 项目状态明确区分已实现、已验证、待验证。
- 每篇文章包含具体问题、方法、证据边界和下一步，而非概念堆砌。
- 中文标点与中英文空格保持一致，技术缩写首次出现时解释。

## 八、Git 与测试

提交信息使用 Conventional Commits。修改页面后至少运行 `npm test`；部署前再执行站内链接检查、`git diff --check` 和公网响应验证。
